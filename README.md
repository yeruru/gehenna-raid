# 게헨나 공대 현황

We CLAN 의 공대(레이드) 참여 기록과 참여율을 관리하는 웹 페이지입니다.
설치할 것 없이 브라우저만 있으면 됩니다.

## 쓰는 법

- **공대 기록** : 날짜 · 시간 · 공대를 고르고 참여한 클랜원을 눌러서 저장합니다.
  - 이름 검색은 **초성**도 됩니다 (`ㅉㄱ` → 짱구). Enter 를 누르면 첫 번째 사람이 선택됩니다.
  - **스크린샷으로 선택** : 공대 명단 화면을 캡처해서 고르거나 `Ctrl+V` 로 붙여넣으면
    이름을 자동으로 읽어서 참여자를 골라 줍니다. 여러 장을 한 번에 넣어도 됩니다.
- **클랜원 관리** : 클랜원 추가 · 이름 변경 · 명단에서 빼기.
  - 게임 닉네임이 명단 이름과 다르면 **닉네임**을 등록해 두세요 (스크린샷 인식에 쓰입니다).

## 사이트에 올라간 기록 갱신하기

모두가 보는 기록은 **`data.json` 한 파일**에 들어 있습니다. 이 파일만 새로 올리면 갱신됩니다.

1. 앱에서 **사이트에 올릴 파일** 버튼을 누릅니다 → 다운로드 폴더에 `data.json` 이 저장됩니다
2. 그 파일을 이 저장소의 `data.json` 자리에 덮어쓰고 올립니다
3. 1분쯤 뒤 사이트에 반영됩니다

이미 사이트에 들어와 본 적 있는 사람은, 새 기록이 올라오면
화면 위에 **"새로 올라온 공대 기록이 있습니다"** 알림이 뜹니다.
누르면 반영되고, 마음에 안 들면 **불러오기 전으로 되돌리기** 로 되돌릴 수 있습니다.
(자기가 입력하던 기록이 말없이 사라지지 않도록 묻고 나서 바꿉니다.)

## 기록은 어디에 저장되나요

기록은 **보고 있는 브라우저 안에만** 저장됩니다 (localStorage).
서버가 없기 때문에 내가 입력한 기록이 다른 사람 화면에 자동으로 나타나지는 않습니다.

- **JSON 내보내기** : 전체 기록을 파일로 백업합니다. 크롬 · 엣지에서는 `json` 폴더를 지정해 두면 그 폴더에 바로 쌓입니다.
- **JSON 불러오기** : 백업 파일을 되돌립니다. 공대 한 건짜리 파일(각 기록의 `JSON` 버튼)은 지금 기록에 **합쳐집니다**.
- 브라우저 기록을 지우면 데이터도 사라지니, 가끔 **JSON 내보내기**로 백업해 두세요.
  (백업 안 한 변경이 있으면 창을 닫을 때 한 번 더 물어봅니다.)

## 참여율 기준

참여율은 그 사람이 **처음 참여한 공대부터** 셉니다.
전체 공대 수로 나누면 나중에 들어온 클랜원이 개근해도 낮게 나오기 때문입니다.
숫자에 마우스를 올리면 `9월 8일 첫 참여 이후 10회 중 8회 참여` 처럼 자세히 보여 줍니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 화면과 앱 전체 로직 |
| `ocr.js` | 스크린샷에서 이름을 읽는 기능 (Tesseract.js) |
| `style.css` | 디자인 (라이트 · 다크 모드 자동) |
| `data.json` | **사이트에 보이는 공대 기록** · 이 파일만 바꿔서 올리면 갱신됨 |

`index.html` 은 기록을 갖고 있지 않고 `data.json` 을 읽어옵니다.
그래서 기록을 갱신할 때 `index.html` 은 건드릴 필요가 없습니다.

내보낸 백업 JSON(`new.json`, `json/`) 과 스크린샷은 개인 데이터라 저장소에 올리지 않습니다 (`.gitignore`).

## 참고

- 스크린샷 인식은 처음 한 번 인터넷 연결이 필요합니다 (인식 도구를 내려받습니다).
- 나머지 기능은 인터넷 없이도 동작합니다.
